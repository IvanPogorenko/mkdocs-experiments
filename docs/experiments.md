# Эксперименты

В рамках демонстрационного исследования рассматриваются три конфигурации HTTP-сервера. Цель экспериментов — сравнить их производительность при одинаковой нагрузке.

Все приведённые ниже данные являются тестовыми и не отражают результаты реальных измерений.

## Эксперимент №1.2. Увеличение количества рабочих процессов

**Цель:** оценить влияние параллельной обработки запросов.

**Конфигурация:**

* 4 рабочих процесса;
* 50 одновременных пользователей;
* одинаковые условия генерации нагрузки;
* отсутствие кэширования.

**Ожидаемый результат:** определение возможного прироста пропускной способности за счёт параллельной обработки.

## Сравниваемые конфигурации

| Конфигурация         | Рабочие процессы | Кэширование |
| -------------------- | ---------------: | ----------- |
| A — базовая          |                1 | Нет         |
| B — параллельная     |                4 | Нет         |
| C — оптимизированная |                4 | Да          |

## Вывод

Эксперименты позволяют последовательно оценить влияние параллельной обработки и кэширования. Для корректного сравнения необходимо обеспечить одинаковые условия тестирования и использовать единый набор метрик.
